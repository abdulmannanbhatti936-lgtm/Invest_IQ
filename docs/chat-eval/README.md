# Chatbot evaluation transcripts (Phase 8)

Produced by `python -m services.chat_eval` (from `services/api`) against a real model, on a temporary dev-database account (Moderate, Rs 100,000 portfolio from the real PSX data, 3-year backtest) that each run deletes afterwards. Every reply goes through the app's own context builder, prompt and figure check. Each `.md` file has a `.jsonl` twin with the raw runs. Automatic verdicts are mechanical; a person read every transcript.

**Do not run these scripts on a demo day**: one full adversarial run uses most of a day's Groq free-tier tokens (Memory.md §4).
