# Phase 1 strings — English / Urdu review

All 103 user-facing strings used by the Phase 1 web screens (login, register, onboarding questionnaire and result, dashboard, navigation, shared messages), exported from `packages/i18n/src/locales/en.json` and `ur.json` on 2026-10-09.

**For the reviewers:** Design.md §10 asks for Urdu that sounds like _a knowledgeable friend explaining money_, not a stiff or bureaucratic translation. Please mark any string that reads unnaturally, is too formal, or is unclear for a first-time investor, and suggest wording. The agent has not changed any Urdu wording.

- `{{name}}`-style placeholders are filled in by the app and must stay exactly as they are in both languages (CI fails if they differ).
- Keys are grouped by screen area. `onboarding.questions.*` are the risk questionnaire; `onboarding.result.caps.*` are the safety-cap explanations.
- Not included: Phase 2/3 strings (`stocks`, `stockDetail`, `prediction`) and the mobile skeleton's `test_key`.
